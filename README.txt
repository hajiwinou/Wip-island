WIP Island — version indépendante

1. Décompressez le ZIP.
2. Conservez WIP_Island.html et le dossier wip_island_assets au même niveau.
3. Publiez les deux dans votre dépôt GitHub (ou ouvrez le HTML localement).

La page fonctionne sans dreamOS. Elle utilise la clé de sauvegarde locale dreamos.wipIsland.game.v1 afin de retrouver la progression si elle est ouverte sur la même origine et dans le même navigateur.
Ne déplacez pas les PNG hors du dossier wip_island_assets.
